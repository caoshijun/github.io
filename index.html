A LITTLE HELP

遇到一点小问题？

哪些浏览器可以烧录？

建议使用电脑上的 Chrome 或 Edge。页面会检测 Web Serial；不支持时仍可下载固件。需要 HTTPS，或本机 localhost / 127.0.0.1。双击本地 HTML、普通局域网 HTTP 和手机浏览器通常不能完成此流程。

串口列表里没有设备？

确认 USB 线支持数据传输，尝试另一个 USB 接口，并关闭 Thonny、Arduino 串口监视器及其他烧录页。必要时按开发板厂商说明安装 USB 转串口驱动。

一直停在连接或初始化？

可尝试按住 BOOT，再按一下 EN / RESET，连接成功后松开 BOOT。烧录过程中保持数据线连接，不要关闭页面或让电脑休眠。

不确定屏幕是哪一种？

先查购买页面、PCB 丝印或原程序驱动。不能只凭 CYD、USB 接口数量或外观判断。型号不匹配时可能出现白屏、反色、偏移；确认引脚匹配后再选对应固件。

Erase device 要不要勾选？

首次从 MicroPython 或其他分区布局迁移，建议先备份，再勾选擦除。已有相同分区布局的 CWBSM 升级可以不擦除。擦除会清空设备内 Wi-Fi、配置和 MFA 账户；不擦除也不等于备份原程序。

可以拿来存重要账户的 MFA 吗？

这是一份社区试用固件。MFA 使用 PIN 和加密存储，但没有硬件安全芯片、Flash 加密或安全启动防护，丢失后仍有离线破解风险。请保留恢复码，不要把它作为关键账户的唯一验证器。
